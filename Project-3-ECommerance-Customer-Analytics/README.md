## E-commerce Customer Analytics Project

## 1. Project Overview
Analysed e-commerce customer data to understand purchasing behaviour, customer retention, repeat purchases, inactive customers and revenue performance.

## 2. Dataset
•	Number of rows: 963
•	Number of columns: 22
•	Contains order, customer, product, acquisition channel, region and sales information.
•	Dataset type: Practice dataset.

## 3. Tools Used
•	Microsoft Excel
•	Excel Formulas
•	PivotTables
•	Power Query
•	Charts
•	Slicers

## 4. Analysis Performed
•	Data cleaning and validation.
•	Revenue, cost, discount and profit calculations.
•	One-time and repeat-customer segmentation.
•	Repeat-customer rate analysis.
•	Customer spending comparison.
•	Inactive-customer investigation.
•	Acquisition channel analysis.
•	Regional revenue per customer.
•	Product category analysis.
•	Payment method comparison.
•	Monthly revenue and order trends.

## 5. Key Findings & Dashboard
•	Total Customers: 240
•	Total Orders: 963
•	Total Net Revenue: PKR 14,236,897.50
•	Total Profit: PKR 3,189,597.50
•	Average Order Value: PKR 14,783.90
•	Repeat-Customer Rate: 92.5%
•	Inactive-Customer Rate: 30%
•	Highest Repeat-Customer Acquisition Channel: Direct (96.88%)
•	Highest Revenue per Customer Region: Sindh (PKR 65,909.69)

## Dashboard:
Interactive Customer Analytics Dashboard containing customer and order KPIs, revenue trends, acquisition channel performance, repeat versus one-time customers, regional revenue and product category performance.
