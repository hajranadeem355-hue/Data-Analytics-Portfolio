## Employee Analytics Project

## 1. Project Overview
Analysed employee data to understand workforce distribution, salary patterns, employee performance, satisfaction and resignation trends.

## 2. Dataset
•	Number of rows: 100
•	Number of columns: 14
•	Contains employee demographics, departments, salaries, attendance, performance and satisfaction information.
•	Dataset type: Practice dataset.

## 3. Tools Used
•	Microsoft Excel
•	Excel Formulas
•	PivotTables
•	Charts

## 4. Analysis Performed
•	Data cleaning and validation.
•	Employee and gender distribution.
•	Department-wise employee analysis.
•	Salary and age analysis.
•	Highest-paid employee identification.
•	Department-wise performance analysis.
•	Employee satisfaction and performance relationship.
•	Overtime and employee satisfaction analysis.
•	Employee resignation-rate analysis.

## 5. Key Findings & Dashboard
•	Total Employees: 100
•	Male Employees: 43
•	Female Employees: 57
•	Average Salary: PKR 102,070
•	Highest Average Salary Department: IT
•	Average Employee Age: 35.69 years
•	Average Performance Rating: 4.31
•	Average satisfaction: 6.58
•	Employee resignation rate: 28%
•	Department with highest resignation rate: HR, with a resignation rate of 41.18%.
Dashboard: Employee Analytics Dashboard containing employee count, average salary, performance rating, resignation rate, department distribution, gender distribution and employee satisfaction.
